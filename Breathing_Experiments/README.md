RIP_Signal_Analysis_BE.m was used for lung volume prediction for the breathing experiments and for optimal model selection
  - Inputs: Chest and abdominal movements, airflow, breathing experiment annotations, subject demographics
  - Includes code used for optimal model selection (10 test equations), with calculated RMSE values
  - Includes code for dissolved oxygen prediction using the estimated (optimal power law equation) and measured lung volume
  -     Final analysis prediction after equation selection in last 3 sections of code  

Tidal_Volume_Correction.m was used to determine the tidal volume increase factor attributed to the added dead space of the breathing apparatus
